# Ayers Software Repair Scoop bucket

Scoop manifests for Ayers Software Repair applications.

```powershell
scoop bucket add ayers-software-repair https://github.com/ayers-software-repair/scoop-bucket
```

Install an application once its manifest is published by its product release workflow.
